Stop publishing a folder, and keep its scope in sync

Usage: aireg watch remove <folder>... [options]
Aliases: aireg watch rm

Options:
  -g, --user  Act on your user scope instead of this project

Learn more:
  Run `aireg --help` for the global options (--json, --verbose, -q, --color, --no-color, --log-level, -y).
  Docs: https://atlanai.github.io/ai-registry/reference/watch/
