Have each coding agent install your registries as plugins it loads

Usage: aireg targets setup [--status]

Options:
      --status  Only report what each coding agent loads, changing nothing

Examples:
  $ aireg targets setup --status  what each coding agent loads

Learn more:
  Run `aireg --help` for the global options (--json, --verbose, -q, --color, --no-color, --log-level, -y).
  Docs: https://atlanai.github.io/ai-registry/reference/targets/
