Print where a target takes each kind, as aireg resolved it

Usage: aireg targets show <id>

Examples:
  $ aireg targets show codex  where Codex gets each kind

Learn more:
  Run `aireg --help` for the global options (--json, --verbose, -q, --color, --no-color, --log-level, -y).
  Docs: https://atlanai.github.io/ai-registry/reference/targets/
