List the harnesses aireg can install into, and which this machine has

Usage: aireg harnesses
       aireg harnesses show <id>
       aireg harnesses check <file>

Actions:
  show   Print where a harness takes each kind, as aireg resolved it
  check  Check a harness file before you use it

Examples:
  $ aireg harnesses  which coding agents this machine has

Learn more:
  Run `aireg --help` for the global options (--json, --verbose, -q, --color, --no-color, --log-level, -y).
  Docs: https://atlanai.github.io/ai-registry/reference/harnesses/
