Take the newest version each registry offers

Usage: aireg update [<name> | <registry>]... [options]
Aliases: aireg upgrade

Options:
      --frozen        Fail with exit status 3 if the lockfile or the manifest would change
      --for <target>  The targets to install into, comma-separated, or * for all of them
      --copy          Copy into each target folder instead of linking
      --dry-run       Print what would change without changing it
  -g, --user          Act on your user scope instead of this project

Examples:
  $ aireg update       the newest of everything
  $ aireg update acme  only what came from acme

Learn more:
  Run `aireg --help` for the global options (--json, --verbose, -q, --color, --no-color, --log-level, -y).
  Docs: https://atlanai.github.io/ai-registry/reference/update/
