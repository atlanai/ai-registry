Print where a harness takes each kind, as aireg resolved it

Usage: aireg harnesses show <id>

Examples:
  $ aireg harnesses show codex  where Codex gets each kind

Learn more:
  Run `aireg --help` for the global options (--json, --verbose, -q, --color, --no-color, --log-level, -y).
  Docs: https://atlanai.github.io/ai-registry/reference/harnesses/
