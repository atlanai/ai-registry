Create a registry in a folder

Usage: aireg registry init [<folder>] [options]

Options:
      --name <name>            The registry's name
      --description <text>     A one-line description of the registry
      --namespace <namespace>  A namespace to create (repeatable)

Examples:
  $ aireg registry init --name acme --namespace engineering -y  a registry with one namespace

Learn more:
  Run `aireg --help` for the global options (--json, --verbose, -q, --color, --no-color, --log-level, -y).
  Docs: https://atlanai.github.io/ai-registry/reference/registry/
