Check a registry against the file spec

Usage: aireg registry validate [<folder>] [--base <ref>]

Options:
      --base <ref>  A git ref to compare released versions against

Examples:
  $ aireg registry validate --base origin/main  check a change before you release it

Learn more:
  Run `aireg --help` for the global options (--json, --verbose, -q, --color, --no-color, --log-level, -y).
  Docs: https://atlanai.github.io/ai-registry/reference/registry/
