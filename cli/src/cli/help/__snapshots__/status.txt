Check installed artifacts against the lockfile, and list the ones nothing manages

Usage: aireg status [-g]

Options:
  -g, --user  Act on your user scope instead of this project

Examples:
  $ aireg status     check this project
  $ aireg status -g  check your user scope

Learn more:
  Run `aireg --help` for the global options (--json, --verbose, -q, --color, --no-color, --log-level, -y).
  Docs: https://atlanai.github.io/ai-registry/reference/status/
