Find artifacts in the registries you have declared

Usage: aireg search <query> [--registry <registry>] [--kind <kind>] [-g]

Options:
  -r, --registry <registry>  Search only this registry, by name or address
      --kind <kind>          Only this kind: plugin, skill or agent
  -g, --user                 Act on your user scope instead of this project

Examples:
  $ aireg search review                     every artifact about review
  $ aireg search lint --kind agent -r acme  only agents, only in acme

Learn more:
  Run `aireg --help` for the global options (--json, --verbose, -q, --color, --no-color, --log-level, -y).
  Docs: https://atlanai.github.io/ai-registry/reference/search/
