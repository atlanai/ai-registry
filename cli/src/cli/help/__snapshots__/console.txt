Open a full-screen view of installed artifacts, jobs and registries

Usage: aireg console [--account <account>]

Options:
      --account <account>  The account to open on

Examples:
  $ aireg console         open the console
  $ aireg console --json  the same state, as data

Learn more:
  Run `aireg --help` for the global options (--json, --verbose, -q, --color, --no-color, --log-level, -y).
  Docs: https://atlanai.github.io/ai-registry/reference/console/
