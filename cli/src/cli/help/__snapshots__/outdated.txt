Check each registry for newer versions of what is installed

Usage: aireg outdated [-g]

Options:
  -g, --user  Act on your user scope instead of this project

Examples:
  $ aireg outdated  what has a newer version

Learn more:
  Run `aireg --help` for the global options (--json, --verbose, -q, --color, --no-color, --log-level, -y).
  Docs: https://atlanai.github.io/ai-registry/reference/outdated/
