Show or clear a stuck write lock

Usage: aireg unlock [-g]
       aireg unlock [-g] <id>

Options:
  -g, --user  Act on your user scope instead of this project

Examples:
  $ aireg unlock  see what holds this project's write lock

Learn more:
  Run `aireg --help` for the global options (--json, --verbose, -q, --color, --no-color, --log-level, -y).
  Docs: https://atlanai.github.io/ai-registry/reference/unlock/
