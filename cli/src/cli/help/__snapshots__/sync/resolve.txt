Settle an artifact edited both here and in the registry

Usage: aireg sync resolve <name> --mine | --theirs [options]

Options:
      --mine       Publish your copy as a new version
      --theirs     Take the registry's copy
      --job <job>  Settle a conflict this job left waiting
  -g, --user       Act on your user scope instead of this project

Examples:
  $ aireg sync resolve pr-review --mine  keep your edit as a new version

Learn more:
  Run `aireg --help` for the global options (--json, --verbose, -q, --color, --no-color, --log-level, -y).
  Docs: https://atlanai.github.io/ai-registry/reference/sync/
