Recommend a skill for a task

Usage: aireg discover search <query>
       aireg discover search --input-stdin

Options:
      --input-stdin  Read a JSON object from a pipe; keeps keys and queries out of command arguments

Learn more:
  Run `aireg --help` for the global options (--json, --verbose, -q, --color, --no-color, --log-level, -y).
  Docs: https://atlanai.github.io/ai-registry/reference/discover/
