Publish artifacts to a registry, as new versions

Usage: aireg publish [<path> | <glob> | <name>]... [options]

Options:
      --to <registry>/<namespace>  Where to publish: a declared registry or a registry folder, and a namespace
      --bump <level>               How far to move the version: patch, minor or major
  -m, --message <message>          The change message, for a registry that records one
      --changed-since <commit>     Only the artifacts whose files changed since this commit
      --force                      Publish an edit made on an older version over a newer one
      --dry-run                    Print what would change without changing it
  -g, --user                       Act on your user scope instead of this project

Examples:
  $ aireg publish .claude/skills/triage --to acme/engineering  a skill, to a team registry
  $ aireg publish pr-review --bump minor                       a new minor version of an edited skill

Learn more:
  Run `aireg --help` for the global options (--json, --verbose, -q, --color, --no-color, --log-level, -y).
  Docs: https://atlanai.github.io/ai-registry/reference/publish/
